# tax_app

A Mobile application for a digital taxi service

## Local Setup

- clone repo locally and open in text editor
- install flutter in the application and set its path in terminal
- run `flutter doctor` and fix any missing dependencies
> xcode and android studio must be installed
- open the simulator of your choice. (on mac run `open -a simulator)`)
- run the application by prompting `flutter run`
> note that the server must be running
